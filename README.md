# استوديو مِرْشاد الخاص

تطبيق ويب عربي متجاوب يحوّل دليل مِرْشاد V1.4 إلى مساحة عمل قابلة للبحث والتصفح، ويضع «رادار مِرْشاد» في الواجهة لمتابعة المستجدات الرسمية وتحويلها إلى قرارات وأفكار محتوى.

## ما يتضمنه الإصدار الأول

- رادار أسبوعي للمستجدات الموثقة مع الأهمية والأثر وفكرة محتوى ومصدر رسمي.
- حالة مقروء/غير مقروء محفوظة على الجهاز ومرشحات للمجال والأولوية.
- بحث شامل في 332 أداة ونموذجًا.
- تصفية حسب 21 مجالًا ودرجة الثقة.
- 24 مسار عمل مع برومبت بداية جاهز.
- مختبر فيديو من 12 مرحلة مع متابعة تقدم محلية.
- محفوظات تعمل على الجهاز.
- تطبيق ويب تقدمي قابل للتثبيت.
- نسخة مؤرشفة كاملة من ملف V1.4 الأصلي.

## التشغيل المحلي

قدّم مجلد `dist` بواسطة أي خادم ملفات ثابت، ثم افتح الصفحة في المتصفح.

## النشر والمراجعة

المستودع وصفحة GitHub Pages عامّان. الرادار يقترح التحديثات، ولا تُعتمد إضافة جديدة في دليل الأدوات قبل مراجعة المالك.
