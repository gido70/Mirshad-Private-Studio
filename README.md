# استوديو مِرْشاد الخاص

تطبيق عربي للأدوات ومسارات العمل والرادار. تتضمن خريطة استخدام من خمس مراحل، وستة برومبتات وظائف مخصصة مع توجيهات منع الأخطاء ونصائح، وبرومبت بدء لكل واحد من المسارات الأربعة والعشرين. صفحة البحث تبدأ بالسؤال «ماذا تريد أن تفعل؟»، ثم تعرض المسارات والأدوات في المجالات المناسبة. العدد الحالي 392 أداة و21 مجالًا و24 مسارًا؛ ليست هذه خدمات موصولة تلقائيًا.

## مصادر الحقيقة والمزامنة

- `dist/data.json`: أسماء الأدوات وتصنيفها ووصفها ومسارات العمل.
- `dist/radar.json`: المستجدات المعتمدة بعد مراجعة بشرية. مهمة الرادار الأسبوعية لا تعدل المستودع تلقائيًا.
- `dist/guide.json`: تعريف النوايا ومرشحات البحث ومعلومات سعر مختارة موثقة بتاريخ ورابط رسمي.
- `dist/index-sections.json`: فهرس بحث مولّد من أقسام الإندكس الأصلي مع روابط مباشرة إلى مواضعها. لتحديث الأصل عند اعتماد نسخة بحثية جديدة، عدّل صفحة المصدر ثم نفّذ `python3 scripts/build-index.py` وأودع الناتج معها. يفحص النشر التطابق عبر `python3 scripts/build-index.py --check`.
- `dist/index.html` و`dist/app.js`: واجهة التطبيق؛ `dist/study.html`: الدراسة الحية، تقرأ ملفات JSON نفسها في كل زيارة. لا تتطلب نسخ أرقام الأدوات يدويًا.
- `dist/archive/Mirshad-AI-Guide-Master-V1.4.html`: نسخة تاريخية مجمدة من الدليل، وليست مصدر التحديثات الجارية. أي نسخة محفوظة خارج GitHub لا تتزامن تلقائيًا.

تغيير بيانات JSON المعتمدة ثم النشر يحدث البحث والتطبيق والدراسة الحية معًا. أقسام الإندكس V1.4 تاريخية وتستعمل مرجعًا بحثيًا؛ بيانات الأدوات المحدثة مصدرها `data.json`، والقرارات والأسعار المختارة في `guide.json`، والمستجدات المعتمدة في `radar.json`. لا تُنسخ التغييرات تلقائيًا إلى الإندكس التاريخي أو إلى ملفات خارج GitHub. تحقق `node scripts/verify.mjs` من الأعداد والمراجع والروابط وبنية العربية؛ يُنفّذ في GitHub Actions قبل رفع الموقع. بعد نجاح النشر تحقق من النتيجة المنشورة. صفحات الأسعار تتغير، لذا راجعها من المصدر الرسمي قبل الشراء. ترتيب البحث يعكس المطابقة والمعلومات المتاحة، ولا يدعي قياس جودة المخرجات.

## التشغيل المحلي

مختبر الفيديو يبدأ بنوع المهمة والموجز، ثم يعرض المرحلة الحالية وإجراءها وزر الانتقال التالي. عند الصوت والأفاتار والمونتاج تظهر خيارات من السجل مع بيان حدود معلومات السعر وروابط المصدر، ويمكن اختيار أداة للتجربة محليًا. تبقى قائمة المراحل سجلًا للتقدم على الجهاز. تفاصيل المسار وبرومبته مرجع اختياري، ومن مساري «إعلان قصير» و«أفاتار متحدث» يوجد انتقال مباشر إلى المختبر. المقارنة لا تختار اشتراكًا أو تشتري رصيدًا تلقائيًا.

الأداة متعددة المجالات WaveSpeedAI تظهر في تصنيفات الصورة والصوت والموسيقى والأفاتار والفيديو والتحرير وثلاثي الأبعاد بسجل واحد، مع رابط تنفيذ InfiniteTalk في الخطوة الثامنة. التقييم يبيّن تحقق المعلومات، ولم تُقَس جودة العربية أو تزامن الشفاه في مِرْشاد بعد.

قدّم مجلد `dist` بواسطة خادم ملفات ثابت، ثم افتح الصفحة في المتصفح. النشر من `dist` على GitHub Pages عبر `.github/workflows/pages.yml`.
